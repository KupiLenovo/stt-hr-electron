PREDUVJETI (instalirati SAMO na PC-u gdje se radi build):
----------------------------------------------------------
1. Node.js 20 LTS
   Preuzmi sa: https://nodejs.org
   Klikni "20.x.x LTS" -> Next -> Next -> Finish

2. Python 3.8+
   Preuzmi sa: https://python.org/downloads
   VAZNO: Pri instalaciji oznaci "Add Python to PATH"

3. Developer Mode (Windows 11)
   Start -> Settings -> System -> For developers
   -> Developer Mode -> ON
   (potrebno da bi build radio ispravno)

================================================================
  KORAK 1 — BUILD APLIKACIJE
  (radi se jednom, na bilo kom PC-u sa Node.js)
================================================================

1. Preuzmi ZIP fajl i raspakiraj ga
   (desni klik na ZIP -> Extract All)

2. Otvori folder "stt-hr-electron" u Windows Exploreru

3. Klikni na address bar (traka sa putanjom gore),
   ukucaj "cmd" i pritisni Enter
   -> otvori se Command Prompt u tom folderu

4. Ukucaj i cekaj (1-3 minute):
      npm install

5. Ukucaj i cekaj (3-5 minuta):
      npm run build:win

6. Kada zavrsi, u folderu "dist\" pronadi:
      STT HR Setup 1.0.0.exe

   NAPOMENA: Ako build stane sa greskom "symbolic link",
   provjeri da li je Developer Mode ukljucen (korak 3 preduvjeta)
   i ponovi npm run build:win.

================================================================
  KORAK 2 — INSTALACIJA NA GLAVNI PC (STUP)
  (ovaj PC cuva sve podatke i mora biti uvijek upaljen)
================================================================

1. Kopiraj "STT HR Setup 1.0.0.exe" na STUP racunar

2. Desni klik -> "Pokreni kao administrator"
   (obavezno — automatski otvara firewall port 3737)

3. Slijedi instalacijski wizard (Next -> Next -> Install)

4. Pokreni STT HR aplikaciju

5. Na prvom ekranu odaberi:
      "Glavni racunar (STUP)"

6. Pojavljuje se upustvo za Port Forwarding.
   Uradi sljedece (jednom zauvijek):

   a) Na STUP PC-u otvori CMD i ukucaj:
         ipconfig
      Zapamti "IPv4 Address" (npr. 192.168.1.105)
      Ovo je LOKALNA IP adresa STUP PC-a.

   b) Udi u router admin panel
      (u browseru otvori: 192.168.1.1 ili 192.168.0.1)
      Pronadi "DHCP Reservation" ili "Static DHCP"
      -> Dodaj rezervaciju za STUP PC sa gore zapamcenom IP
      (tako STUP PC uvijek dobija istu lokalnu IP)

   c) Pronadi "Port Forwarding" (ili NAT / Virtual Server)
      -> Dodaj novo pravilo:
         Naziv:         STT HR
         Protocol:      TCP
         External port: 3737
         Internal IP:   [lokalna IP iz koraka a]
         Internal port: 3737
      -> Snimi

   d) Pronadi JAVNU IP adresu STUP-a:
      Otvori browser i idi na: https://whatismyip.com
      Zapisi tu IP adresu — koristit ce je ostale lokacije.
      Primjer: 89.172.45.12

7. Klikni "Razumijem, nastavi na prijavu"

8. Odaberi lokaciju -> odaberi svoje ime -> unesi PIN

   NAPOMENA: Svaki radnik pri PRVOJ prijavi koristi PIN 0000
   i bit ce zatrazeno postavljanje novog 4-cifrenog PIN-a.

================================================================
  KORAK 3 — INSTALACIJA NA OSTALE RACUNARE
  (SCC, Merkator Lozionicka, i sve ostale lokacije)
================================================================

1. Kopiraj "STT HR Setup 1.0.0.exe" na svaki lokalni racunar

2. Desni klik -> "Pokreni kao administrator" -> instaliraj

3. Pokreni STT HR aplikaciju

4. Na prvom ekranu odaberi:
      "Lokalni racunar (Maloprodaja)"

5. Upisi JAVNU IP adresu STUP racunara (iz Koraka 2d)
   Primjer: 89.172.45.12

6. Klikni "Spoji se"
   -> Ako je uspjesno: prikazuje se ekran za odabir lokacije
   -> Ako ne radi: provjeri da li je STUP PC upaljen i
      da li je IP adresa ispravna

7. Ova postavka se pamti automatski.
   Sljedeci put aplikacija se direktno spaja.

================================================================
  KORAK 4 — POSTAVLJANJE PIN-OVA ZA RADNIKE
================================================================

Svaki radnik pri prvoj prijavi:
1. Odabere svoju lokaciju
2. Klikne svoje ime
3. Unese privremeni PIN: 0000
4. App trazi postavljanje novog PIN-a
5. Upise zeljeni 4-cifreni PIN dva puta

Admin moze resetovati PIN bilo kom radniku:
-> Otvori "Radnici" u meniju
-> Klikni zuto dugme sa kljucem pored radnika
-> PIN se resetuje na 0000

Radnik moze promijeniti vlastiti PIN:
-> Sidebar (lijevi meni) -> dno -> "Promijeni PIN"

================================================================
  VAZNE NAPOMENE
================================================================

STUP PC:
- Mora biti UPALJEN dok rade ostale lokacije
- STT HR aplikacija mora biti POKRENUTA
- Preporucujemo postavljanje na Windows autostart

BAZA PODATAKA:
- Cuva se na STUP PC-u:
  C:\Users\[korisnik]\AppData\Roaming\STT-HR\stt-hr.db
- NE brisati ovaj fajl!
- Radi BACKUP jednom sedmicno:
  Kopiraj stt-hr.db na USB ili Google Drive

AKO NESTO NE RADI:
- IP servera se moze promijeniti u sidebar -> "Promijeni server"
- Ako STUP PC promijeni lokalnu IP, azuriraj Port Forwarding
- Ako zaboravis PIN -> kontaktiraj admina za reset
