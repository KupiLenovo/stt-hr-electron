KAKO RADI
---------
aiERP je cloud sistem: podaci su na serveru firme, a desktop
aplikacija je prozor prema tom serveru, uz vezu sa fiskalnim
printerom i offline kasu (računi se čuvaju lokalno dok nema
interneta i pošalju se kad se veza vrati).

================================================================
  1) INSTALACIJA
================================================================

1. Preuzmi instalaciju (fajl "aiERP Setup X.Y.Z.exe"):
   https://github.com/KupiLenovo/stt-hr-electron/releases/latest

2. Pokreni je i potvrdi administratorska prava.

3. Prati korake instalacije. Na desktopu se pojavi prečica "aiERP".

================================================================
  2) PRVO POKRETANJE — POVEZIVANJE S FIRMOM
================================================================

1. Pokreni aiERP.

2. Na ekranu "Poveži aplikaciju sa svojom firmom" upiši adresu
   servera svoje firme, npr.:   firma.aierp.ba
   (za STT d.o.o.:              app.aierp.ba)

3. Klikni "Poveži". Aplikacija provjeri da na toj adresi radi
   aiERP server i od tada se otvara direktno.

   - Veza je uvijek šifrovana (https). Adresa bez https se ne prihvata.
   - Adresa se kasnije mijenja preko menija:
       Aplikacija -> Promijeni server firme...

================================================================
  3) PRIJAVA
================================================================

1. Unesi pristupni kod radnog prostora (dobiješ ga od administratora;
   računar ga zapamti).

2. Izaberi svoje ime i unesi PIN.
   Pri PRVOJ prijavi PIN je 0000 — aplikacija odmah traži da
   postaviš svoj.

3. Poslije 5 pogrešnih PIN-ova zaredom nalog se privremeno zaključa
   (1 minut, pa duže). Voditelj ga odmah otključa resetom PIN-a.

================================================================
  4) AŽURIRANJE
================================================================

Aplikacija se ažurira sama: nova verzija se preuzme u pozadini i
instalira pri sljedećem zatvaranju aplikacije.
Ručno: Aplikacija -> Provjeri ažuriranja.

================================================================
  AKO NEŠTO NE RADI
================================================================

- "Nema veze sa serverom": provjeri internet — aplikacija sama
  pokušava ponovo svakih nekoliko sekundi. Ako se firma preselila
  na drugi server, klikni "Promijeni adresu servera".
- Zaboravljen PIN: administrator ili voditelj ga resetuje na
  profilu radnika.
- Adresa servera i verzija aplikacije: Aplikacija -> Info o serveru.

================================================================
  NADOGRADNJA SA VERZIJE 4.1.x (samo STT)
================================================================

Računari sa verzijom 4.1.x sami pređu na https://app.aierp.ba pri
prvom pokretanju verzije 4.2.0. Prijava, zapamćen pristupni kod i
veza kiosk uređaja se prenesu — niko ništa ne upisuje.

================================================================
  ZA RAZVOJ
================================================================

  npm ci          instalacija zavisnosti
  npm start       pokretanje iz koda
  npm test        testovi adrese servera

  STT_SERVER_URL=https://...   nadjačava adresu servera (samo razvoj)
  AIERP_USER_DATA=<folder>     odvojen profil (npr. test "prvog pokretanja")

  Izdanje: podigni verziju u package.json, pa
    git tag vX.Y.Z && git push origin vX.Y.Z
  GitHub Actions napravi Windows i Mac instalaciju i objavi release;
  instalirane aplikacije ga vide pri sljedećoj provjeri ažuriranja.
